The connector `ext-catalog-connection-postgres` (manifest id
`io.github.mosaikit.ext.catalog.connection.postgres`) adds a PostgreSQL database to the connection framework (EXT-010).
It is an extension of its own: an installation that does not need it does not carry it, and connections
made with it show as unavailable when it is removed (MK-135).

## History

- 2026-10-14: split from GP-957, a requirement of a product that composes these extensions; the generic part is here, the rest stays with that product.
- 2026-10-15: planned in the phase of the catalog (F06), with the maintainer's approval: a product needs a table of a database connection offered for a use of its own.

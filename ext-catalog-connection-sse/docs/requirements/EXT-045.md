The connector `ext-catalog-connection-sse` (manifest id
`io.github.mosaikit.ext.catalog.connection.sse`) adds an SSE endpoint to the connection framework (EXT-010).
It is an extension of its own: an installation that does not need it does not carry it, and connections
made with it show as unavailable when it is removed (MK-135).

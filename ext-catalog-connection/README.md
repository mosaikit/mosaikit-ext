# ext-catalog-connection

Manifest id `io.github.mosaikit.ext.catalog.connection`.

The framework of connections to data sources: the list, the creation path, the detail, the source picker the editors of other extensions open, encrypted credentials, the content model and the SQL workspace. Each kind of source is a connector, `ext-catalog-connection-<source>`.

The code arrives in this folder, which holds everything of the extension (ADR-0001). Its requirements are in [`docs/requirements/`](docs/requirements/), one `EXT-nnn.md` each; those that span several extensions are in `docs/requirements/` at the root of the repository.

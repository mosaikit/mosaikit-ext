title: A connection is edited from its detail panel
area: connections
priority: P1
status: done
depends: [EXT-013, EXT-016]
estimate: [1, 2]
acceptance:
  - The Edit command of the detail panel opens the creation form of that type, filled in, with the type fixed.
  - Saving updates the connection and keeps every setting the form does not show (method, authentication, headers).
  - The card and the detail show the new values after saving, without reloading the page.
---

"Edit" opens the same form used to create the connection, filled in, in two steps since the type
cannot change. The update starts from what the server returned and changes only the fields the form
shows.

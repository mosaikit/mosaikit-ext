---
id: EXT-024
title: Connections are organized by kind of source, each section counted
area: connections
priority: P1
status: proposed
depends: [EXT-025]
estimate: [8, 12]
acceptance:
  - The navigation of the connections page lists the categories contributed by the installed connectors, each with the number of its connections.
  - Every connector type appears in exactly one category.
  - A category that could not be counted (for example because a request was refused with 403) shows a dash with the reason, not zero.
  - An empty category says what will land in it instead of showing "0 results".
---

Sources are grouped by what they are, not by the protocol used to reach them, so every new kind of
source already has a section to land in. Each count distinguishes "none", "some" and "could not count".

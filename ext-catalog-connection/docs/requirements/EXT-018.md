---
id: EXT-018
title: A connection declares what it contains by inspecting it, not by its type
area: connections
priority: P1
status: done
depends: [EXT-013]
estimate: [4, 6]
acceptance:
  - For a REST endpoint and for SSE, Kafka and WebSocket streams the connection step shows a sample of the response or messages and classifies its shape.
  - For a database the list of tables shows the columns of each table with their types.
  - A connector can add facts it finds by inspection (for example a column holding coordinates), and the parts offer only the uses those facts allow.
  - A source that cannot be inspected says why instead of showing an empty list.
---

What a source can be used for is not guessed from its type: a REST path can serve anything, a table
may hold only codes. The framework asks the connector to **look**: read the first rows, show a sample of
a response or of stream messages, list the tables with their columns. What was found is shown on the
connection step and in the detail, and the commands that create resources from a part light up on it.

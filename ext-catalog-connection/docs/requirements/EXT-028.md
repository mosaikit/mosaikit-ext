title: A SQL workspace queries connections and promotes results to sources of other extensions
area: connections
priority: P1
status: proposed
depends: [EXT-010]
estimate: [12, 18]
acceptance:
  - The editor completes table and column names from the schema of the chosen connection.
  - Running a query shows a preview of the rows returned by the source, capped at the row limit.
  - One command turns a result into a dashboard source, or into a source of another installed extension that declares the use.
  - A saved query is visible to the other members of the organization and to nobody outside it.
---

An editor with schema completion, a preview of the result and one click to promote the result to a
source other extensions read; queries run on the server and are saved per organization. Natural language
to SQL is a separate requirement on top of this editor.

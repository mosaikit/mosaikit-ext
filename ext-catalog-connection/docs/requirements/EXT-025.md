acceptance:
  - The connections page and the source picker show the same categories, with the same names and order.
  - Every connector type and curated entry belongs to exactly one category, and a test fails when one has none or two.
  - A connector can add a category of its own, and it appears in every place that shows the taxonomy.
---

One list of categories, declared once by the framework and extended by connectors, says what belongs
to each. Sources are classified by use, not technology: generic REST is a transport and lives in "other
sources". Other extensions read the same taxonomy, so a product that shows sources elsewhere (an Add
dialog of its own) uses the same names.

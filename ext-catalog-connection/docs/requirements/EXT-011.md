  - Every connection configured in the organization appears as a card in one grid, with a row view next to it.
  - The Type filter lists only the types actually configured, each with the number of connections it matches.
  - Two connections of the same type show two different generated thumbnails, derived from their names.
  - A connection with an uploaded thumbnail shows that image instead of the generated one.
---

The connections page shows every source the organization has configured, whatever its connector,
in one list with the header, tabs and filter column of the other list pages. The left column filters
instead of navigating: a Type list computed from the connections themselves, so it contains only the
types really present. Each connection has a thumbnail, uploaded or generated from its name (hue and
silhouette from a hash of the name), so that nine connections of one type do not look alike.

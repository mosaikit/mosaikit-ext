---
id: EXT-079
title: The data of a dashboard widget is chosen from the connections, not pasted
area: dashboards
priority: P1
status: planned
depends: [EXT-026]
estimate: [4, 6]
acceptance:
  - The data tab of a widget shows the chosen connection and part with its type and the number of columns read.
  - The axes of a chart are chosen among the columns read from the source.
  - Reading parameters (row limit, filter, refresh interval, stream buffer) are set per widget under Advanced, and two widgets on the same table can use different ones.
  - A widget without a chosen source says so and offers to choose one.
---

Choosing a table inside a connection already says how it is read, so the protocol list disappears as
the first choice: the widget opens the source picker of the framework (EXT-026). Under Advanced remain
the reading parameters, which belong to this use of the source.

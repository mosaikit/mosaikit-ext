  - A widget can be bound to static data, an authenticated REST endpoint, a SQL query and a process output, and shows their data.
  - A widget bound to a WebSocket, SSE, Kafka or MQTT connection updates as messages arrive.
  - A widget can read a source kind contributed by another extension through the source contract.
  - Credentials of a source are never sent to the browser.
---

A dashboard widget reads static data and the connections of `ext-catalog-connection` (REST, SQL,
streams), and process outputs. Streaming sources go through the server, so credentials stay there. Other
extensions contribute further source kinds through a contract (MK-134).

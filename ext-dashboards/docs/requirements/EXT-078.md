---
id: EXT-078
title: A widget bound to a source configures itself from the key fields the source declares
area: dashboards
priority: P2
status: proposed
depends: [EXT-079]
estimate: [1, 2]
acceptance:
  - A widget created from a template bound to a source shows its chart at the first load.
  - A widget uses the date, value and label fields declared for the source when the author chose none.
  - An axis chosen by hand is kept after reloading the dashboard.
---

A source can declare which column is the date, the value, the label and the identifier. A widget bound
to it, whether picked by hand, created from a template or duplicated, uses those key fields on every
load, so its chart is never empty. A choice already made by the author is never overwritten.

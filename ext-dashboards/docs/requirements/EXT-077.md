acceptance:
  - The full definition of a widget is shown as JSON, and applying an edited JSON changes the rendered widget.

  - A widget copied from one dashboard and pasted in another renders the same there.

The complete definition of a widget can be viewed, edited and applied as JSON, and widgets can be copied from one dashboard to another.

# ext-catalog-connection-snowflake

Manifest id `io.github.mosaikit.ext.catalog.connection.snowflake`.

The connector to Snowflake, a cloud data warehouse: one connector of `ext-catalog-connection`, discovered by the framework.

The code arrives in this folder, which holds everything of the extension (ADR-0001). It has no requirement of its own yet: the cloud data warehouses are one requirement, EXT-049, in `docs/requirements/` at the root of the repository, since it spans this connector and its siblings.

id: EXT-050
title: A federated query engine connects as an ordinary connection
area: connections
priority: P1
status: proposed
depends: [EXT-010]
estimate: [2, 4]
acceptance:
  - An organization manager registers a Trino connection with host, port and catalog, and the health check reports offline when the coordinator does not answer a SELECT 1.
  - A query on the engine returns its rows with the row limit and paging of the framework.
  - A column type the engine does not describe is returned as text, never dropped.
---

A federated query engine is not embedded: the connector `ext-catalog-connection-trino` talks to it
through its JDBC driver, with the same encrypted credentials, health check and query executor. One query
spans the databases and columnar files of the organization without copying them.

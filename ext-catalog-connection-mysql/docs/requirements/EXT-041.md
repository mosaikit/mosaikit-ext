acceptance:
  - With `ext-catalog-connection-mysql` installed, New connection offers a MySQL or MariaDB database with its connection form.
  - The connection test returns either a preview of the content or the error of the remote system.
  - The connector lists tables with their columns, and runs queries with the row limit.
  - Credentials of the connection are stored encrypted and never returned by the API.
---

The connector `ext-catalog-connection-mysql` (manifest id
`io.github.mosaikit.ext.catalog.connection.mysql`) adds a MySQL or MariaDB database to the connection framework (EXT-010).
It is an extension of its own: an installation that does not need it does not carry it, and connections
made with it show as unavailable when it is removed (MK-135).

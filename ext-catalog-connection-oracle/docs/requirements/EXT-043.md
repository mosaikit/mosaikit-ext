  - With `ext-catalog-connection-oracle` installed, New connection offers an Oracle database with its connection form.
  - The connection test returns either a preview of the content or the error of the remote system.
  - The connector lists schemas and tables with their columns, and runs queries with the row limit.
  - Credentials of the connection are stored encrypted and never returned by the API.
---

The connector `ext-catalog-connection-oracle` (manifest id
`io.github.mosaikit.ext.catalog.connection.oracle`) adds an Oracle database to the connection framework (EXT-010).
It is an extension of its own: an installation that does not need it does not carry it, and connections
made with it show as unavailable when it is removed (MK-135).

- 2026-10-14: split from GP-957, a requirement of a product that composes these extensions; the generic part is here, the rest stays with that product.

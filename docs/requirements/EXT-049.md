  - An organization manager registers a BigQuery or Snowflake connection, and the connection test reports success or the error returned by the warehouse.

  - A dashboard widget bound to a query shows the rows the warehouse returned.

Connectors to cloud data warehouses, BigQuery and Snowflake first (`ext-catalog-connection-bigquery`,
`ext-catalog-connection-snowflake`), Databricks next. They reuse what every connection has: encrypted
credentials, connection test, health check and the query executor with a row limit. A product that
reads special column types (geometries, for example) adds that reading in its own extension.

title: Each extension is a self-contained folder of the repository
area: common
priority: P1
status: in-progress
depends: [MK-132]
estimate: [2, 3]
acceptance:
  - Each extension's folder holds its build, sources, tests, changelog, README and requirements, and builds alone from that folder with the published Mosaikit SDK.
  - A check of the CI fails when a file of an extension refers to a file outside its folder, other than through a published package.
  - Extracting a folder with git filter-repo gives a repository that builds and passes its tests without changes.
---

ADR-0001: the extensions stay in one repository, but each one must be movable to a repository of its
own without rework. The folder is the unit; the root keeps only licence, CI, ADRs and the
requirements shared by several extensions.

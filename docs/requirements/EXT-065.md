acceptance:
  - An extension that only declares a dashboard widget in its manifest shows the widget in the widget palette, with its icon, group and badge.
  - An extension that declares a process node shows the node in the palette and the executor runs it with the declared ports.
  - A contribution whose declaration lacks a required field is refused at start with a problem that names the field, and the other contributions keep working.
  - The built-in widgets, nodes and connectors of this repository are declared through the same contract, with no list of them in code.
---

The common extensions are extended in three places: dashboard widgets, process nodes and connectors.
Each is declared, not inferred: identifier, group, how it opens, badge, state. They are contracts between
extensions (MK-134) published by `ext-dashboards`, `ext-processes` and `ext-catalog-connection`, so a
third party contributes through its own extension package.

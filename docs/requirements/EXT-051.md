id: EXT-051
title: Arrow Flight SQL and ADBC carry columnar results from warehouses and federated engines
area: connections
priority: P1
status: proposed
depends: [EXT-049, EXT-050]
estimate: [8, 12]
acceptance:
  - A query on a source that exposes Flight SQL is transferred in Arrow format, and the same query returns the same rows as over JDBC.
  - A source without Flight SQL keeps working over JDBC with no change visible to the user.
  - The browser receives a large result as Arrow without a JSON step.
---

The SQL dialect stays, the pipe changes: Flight SQL delivers columns rather than rows, and an ADBC
driver speaks it without rewriting the query executor. The gain is in transfer, about an order of
magnitude on results of millions of rows.

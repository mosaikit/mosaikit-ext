---
id: EXT-030
title: Query results beyond the row limit are produced as an asynchronous job and a columnar file
area: connections
priority: P2
status: proposed
depends: [EXT-028, MK-038, MK-041, MK-093]
estimate: [6, 9]
acceptance:
  - A query whose result exceeds the interactive row limit can be run as a job, and the page keeps working while it runs.
  - When the job ends the person receives a notification in the activity feed with a download link to a Parquet file holding all the rows.
  - The link stops working after its declared expiry, and a person without access to the connection cannot use it.
---

The interactive row limit stays, because it protects the browser, but it gets a way out: the query
becomes a job, the result a columnar file in storage, and a notification says when it is ready, with a
link that expires. The platform provides notifications, file store and signed links.

area: processes
priority: P1
status: planned
depends: [EXT-090]
estimate: [3, 5]
acceptance:
  - A dry run executes the graph on sample inputs without writing to any destination.
  - During the dry run the node in execution is highlighted, and the log panel shows each node's messages.
  - At the end the result of the selected node is previewed, with the preview a contributing extension declares for its data types.
---

The graph is tried before it runs for real: a preview of the result, the node in execution highlighted,
and the log. People find wrong parameters before they write anything.

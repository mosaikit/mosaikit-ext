---
id: EXT-032
title: The identity of the person reaches the source, so its row and column policies apply
area: connections
priority: P2
status: proposed
depends: [MK-061]
estimate: [8, 12]
acceptance:
  - A query run by a person on a connection set to propagate identity reaches the source with that person's identity, as the source's own query history shows.
  - Two people with different row policies in the source see different rows from the same widget.
  - A connection without identity propagation keeps using its service account.
---

The token of the person is propagated to the warehouse or query engine instead of a single service
account, so the policies the organization wrote there keep applying. Obtaining such a token is a
capability of the platform (MK-061).

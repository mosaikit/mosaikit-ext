---
id: EXT-103
title: Each extension is published as its own package with its own version
area: common
priority: P1
status: in-progress
depends: [EXT-102]
estimate: [3, 5]
acceptance:
  - Pushing a tag ext-<name>/vX.Y.Z publishes only that extension, as io.github.mosaikit.ext:ext-<name> with version X.Y.Z.
  - A tag whose version differs from the version in the extension's build is refused before anything is published.
  - Each extension has its own changelog, and the release notes of a tag contain only that extension's entries.
  - A product declares an extension by package and version and gets only that extension and the extensions it requires.
---

ADR-0001: a product that needs one extension takes one package, never the repository. Versions move
independently, so a fix to one extension does not release the others.

## History

- 2026-10-14: written (ADR-0001).
- 2026-10-15: in progress.
- 2026-10-15: in progress. `tools/release.py` checks a tag `ext-<name>/vX.Y.Z` against the build,
  the manifest, `package.json` and the changelog before anything is published, extracts the
  changelog section of the version as release notes, writes the POM to publish with the required
  extensions as dependencies (ranges of MK-132 in Maven syntax, optional ones left out) and the
  bundle of Maven Central, and resolves what a product gets with an extension; its tests
  (`tools/test_release.py`) cover the refusal of a mismatched tag, the notes of one extension only
  and the closure of required extensions. The release workflow waits for review; the publication
  itself is shown by the first tag.

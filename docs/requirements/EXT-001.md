id: EXT-001
title: Files of an organization are kept in folders and sub-folders
area: files
priority: P1
status: proposed
depends: [MK-054]
estimate: [6, 9]
acceptance:
  - A person creates a folder at the root of the files of the organization and a sub-folder inside it, and both appear in the tree and in the list of the parent.
  - A folder shows its files and sub-folders with name, size, owner, last change and sharing state, sorted by name or by date.
  - The path of the open folder is shown as breadcrumbs, and each step opens that folder.
  - Opening the address of a folder the person cannot read answers not found, the same as a folder that does not exist.
---

`ext-catalog` is the file manager of an organization, in the shape people know from the files of
a team workspace: a tree of folders and sub-folders on the left, the content of the open folder in the
middle, breadcrumbs above it. Folders are resources of the extension registered with the kernel (MK-054),
so search, sharing and audit apply to them like to any other resource. Files are not interpreted here:
an extension that understands a format (a table, an image, a document) contributes its preview or its
actions through a contract (MK-134), and the file manager works without it.

---
id: EXT-104
title: The CI of a pull request tests only the extensions it changes and those that depend on them
area: common
priority: P2
status: in-progress
depends: [EXT-102, MK-132]
estimate: [2, 4]
acceptance:
  - A pull request that changes one extension builds and tests that extension and the extensions that require or use it, and no other.
  - The dependencies between extensions are read from their manifests, not from a list in the CI.
  - A change to a file of the root (CI, shared requirements) runs every extension.
  - The required check of the pull request passes or fails as one, whatever set of extensions ran.
---

ADR-0001: one repository must not mean one slow pipeline. Changes to the workflows wait for the
review of a maintainer, as every change to `.github/`.

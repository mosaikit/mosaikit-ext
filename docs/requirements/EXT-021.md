---
id: EXT-021
title: Creating a resource from a connection produces a working result
area: connections
priority: P1
status: proposed
depends: [EXT-016, EXT-026]
estimate: [1, 2]
acceptance:
  - '"Create a dashboard" from a table opens a widget that shows rows of that data.'
  - '"Create a process" from a piece opens a process whose input node reads that piece.'
  - Where no working configuration is known (for example a stream for a widget that cannot read one), the command says so instead of opening an empty editor.
---

The shortcuts of the detail must build what the manual gesture builds; failing silently (a blank
widget, a node that reads nothing) looks like success and is the worst way to fail.

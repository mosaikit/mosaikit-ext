acceptance:
  - A process with a cron expression runs at the scheduled times, and each run appears in the run history as scheduled.
  - A process bound to the event "file added" of a folder of the file manager runs when a file is added there and receives that file as input.
  - Disabling the schedule stops further runs.
---

A process starts on its own from a cron expression, or when something happens on the platform (MK-085),
such as a file added to a folder of `ext-catalog` (EXT-001). When the file manager is not installed the
event is not offered.

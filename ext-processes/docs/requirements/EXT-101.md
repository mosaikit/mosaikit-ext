id: EXT-101
title: A process runs partitioned and resumes per partition
area: processes
priority: P1
status: proposed
depends: [EXT-092]
estimate: [10, 15]
acceptance:
  - A process run with partitioning executes the graph once per partition, in parallel, and merges the results.
  - A run interrupted after most partitions resumes from the unfinished partitions, not from the start.
  - A finished run reports how many partitions it touched and which were empty.
  - An extension can contribute a kind of partitioning (table partitions are built in).
---

The same graph runs over partitions, in parallel, with a checkpoint per partition: a job that fails at
ninety percent restarts from there. Table partitions are built in; other kinds (a grid of tiles, for
example) are contributed by extensions.

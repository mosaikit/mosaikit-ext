---
id: EXT-095
title: Script nodes and custom nodes added by extensions without changing the editor
area: processes
priority: P2
status: planned
depends: [EXT-090, MK-020]
estimate: [5, 8]
acceptance:
  - A script node runs the code written in it on its input and returns its output to the next node, within a time and memory limit.
  - An extension that contributes a node makes it appear in the palette after installation, with no change to ext-processes.
  - A contributed node runs on the server like built-in nodes and its runs appear in the run history.
  - A process holding a node of an extension that is not installed opens with the placeholder of the platform (MK-135) on that node and refuses to run, naming the extension.
---

A node can be a script, and new nodes are extensions extending `ext-processes` through the node
contract (MK-020, EXT-065), bringing their manifest, dialog and executor. Script nodes have limits on time
and memory.

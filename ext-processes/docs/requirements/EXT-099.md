area: processes
priority: P2
status: proposed
depends: [EXT-098, MK-041, MK-044, MK-055, MK-087]
estimate: [5, 8]
acceptance:
  - A report set to mail delivery arrives as an attachment to the listed addresses after the execution.
  - A report set to bucket delivery appears as an object in the configured bucket.
  - A report published with a 30-day retention is no longer reachable by its link after 30 days.
---

Delivery is part of the report template: mail (MK-087), a storage bucket, or a shared file with a link
and its own retention (MK-044, MK-055), in the file manager when it is installed.

---
id: EXT-096
title: Any process node can declare a source field that adds and wires the source node
area: processes
priority: P1
status: planned
depends: [EXT-026]
estimate: [5, 8]
acceptance:
  - A node whose manifest declares a field of type source shows a source row that opens the shared picker, also for third-party nodes.
  - Choosing a source in the field creates the source node on the canvas and connects it to the declared port.
  - Cutting that connection empties the field, and the created source node can be reused for another branch.
  - Running the process reads the chosen source through the created node.
---

Not a new node but a **field type** that nodes declare in their manifest, so any node needing data gets
the same row and the source picker of the connections (EXT-026). Choosing a source creates the source node
and wires it: the field is a shortcut for drawing part of the graph.

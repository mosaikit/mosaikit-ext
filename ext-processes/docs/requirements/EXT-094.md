acceptance:
  - Saving a process creates a new version; a run records the version it used, and an earlier version can be opened and restored.
  - A long asynchronous node (for example a remote job) resumes after a server restart and the run completes.
  - A failed run notifies its owner in the activity feed and by e-mail, and appears in the audit log with the process, version and error.

A process has versions; long nodes run asynchronously and resume by themselves; a failure is notified
(MK-038, MK-088) and recorded in the audit (MK-059).

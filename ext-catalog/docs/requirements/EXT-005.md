---
id: EXT-005
title: A file keeps its previous versions, which can be restored
area: files
priority: P3
status: proposed
depends: [EXT-002]
estimate: [4, 6]
acceptance:
  - Uploading a file with the name of an existing one in the same folder offers to keep both or to add a new version.
  - The versions of a file are listed with author, date and size, and an earlier version can be downloaded or restored as the current one.
  - The number of versions kept per file is set per organization, and the oldest beyond it are removed.
---

Optional, later: versions of a file as in team file spaces. Until it is done a new upload with the
same name asks whether to replace the file or keep both.

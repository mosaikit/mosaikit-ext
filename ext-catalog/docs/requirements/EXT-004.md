  - In a portable installation the uploaded files are written on the local disk through the file service of the kernel, and on a server installation in the configured S3-compatible bucket, with no change in the extension.
  - Downloads go through signed, expiring links of the platform (MK-093); an expired link is refused.
  - Deleting an organization removes its files from the storage.
---

`ext-catalog` holds no storage of its own: the content of files goes to the file service of the
kernel (MK-041), which writes to the filesystem in the portable distribution and to an S3-compatible
bucket on a server. The extension keeps only the tree, the names and the metadata in its schema.

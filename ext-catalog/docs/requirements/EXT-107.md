id: EXT-107
title: A kind of file reads the content of its files through the file manager, without a copy
area: files
priority: P2
status: in-progress
depends: [EXT-105, MK-093]
estimate: [1, 2]
acceptance:
  - The contract of file kinds gives the extension of a kind a signed, expiring link to the content of a file of its kind, usable by a server process of that extension outside the request of a person.
  - The link stops working when the file is deleted or replaced, and a new link serves the new content.
  - An extension of a kind can do its work on the content without keeping a copy of it, so a file counts once against the storage quota.
---

An extension that loads the content of its files elsewhere (a database, a tile store) reads it in a
job, outside the request of the person who uploaded it. Without a link to the content it keeps a
copy of every file, which doubles the storage used.

---
id: EXT-106
title: A file of a kind whose extension is absent shows the placeholder of the platform
area: files
priority: P1
status: in-progress
depends: [EXT-105, MK-135]
estimate: [1, 2]
acceptance:
  - A file recognized by a kind whose extension is not active in the organization shows in the list and in its detail the placeholder of the platform (MK-135), saying which kind is missing and, to administrators, which extension to install or turn on; the file can still be downloaded, moved, renamed, shared and deleted.
  - When the extension comes back, the open page shows the file with its kind again, without a reload.
  - The kind recorded on the file and its state are kept while the extension is absent.
---

A file manager that only shows such a file as a plain file hides that something is missing: people
do not know why the preview and the actions are gone, and administrators do not know what to turn
on. The placeholder of the platform says it the same way every extension does.

id: EXT-002
title: Files and folders are uploaded, downloaded, moved, renamed and deleted
area: files
priority: P1
status: in-progress
depends: [EXT-001, MK-041, MK-076]
estimate: [6, 9]
acceptance:
  - Dropping several files and a folder from the computer onto a folder uploads them with the folder structure kept, with progress per file.
  - A file or folder moved to another folder by drag and drop or by the Move command appears there and disappears from where it was, with its sharing kept.
  - Renaming to a name already used in the same folder is refused with a message naming the existing item.
  - Deleting a folder asks for confirmation with the number of items it holds, and the deleted items are no longer listed nor downloadable.
  - A file is downloaded with its name, and several selected items are downloaded as one archive.
---

The everyday gestures of a file manager, with the same behaviour in the list, in the tree and by
keyboard. An upload too large for the quota of the organization (MK-076) is refused before it starts,
with the limit named. Moving and renaming keep the identity of the item, so links and references held
by other resources keep working.
